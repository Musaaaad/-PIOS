# PostgreSQL & Object Storage Integration Candidate v1.7

This directory contains an isolated PostgreSQL 16 + MinIO candidate environment, post-import verification SQL, local evidence lifecycle/access-control tests, and OIDC positive/negative/site-isolation tests.

The Docker/MinIO/PostgreSQL runtime was prepared but not started in the build environment because Docker/Podman/PostgreSQL executables were unavailable. Local storage and offline OIDC tests were executed.
