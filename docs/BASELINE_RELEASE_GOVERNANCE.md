# Baseline Release Governance

A baseline release is an immutable, hashed representation of one 266-item readiness snapshot.

## Classifications
- OperationalBaseline: may be published with gaps and critical open actions. It is the factual starting point.
- EvidenceReady: allowed only when the snapshot has no critical open actions, overall status EvidenceReady, and every ESR group is green.

The release explicitly states that evidence readiness is not a CBAHI accreditation score or institutional accreditation decision.
