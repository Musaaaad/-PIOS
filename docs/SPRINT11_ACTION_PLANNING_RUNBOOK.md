# Sprint 11 Action Planning Runbook

- Confirm recommendation status is `HumanApprovedForPlanning`.
- Create or open a review session.
- Add the recommendation and record one of: AdoptForPlanning, Reject, Defer, RequestRevision.
- Create the action plan only for an adopted recommendation.
- Add at least one task with owner and due date.
- Submit the plan and record an independent Approval review.
- Start execution and complete tasks with evidence references and notes.
- When a formal issue is confirmed, create a separate conversion request.
- Record conversion approval and explicitly execute Finding or CAPA creation.
- Record a CompletionVerification review.
- Complete the plan without closing linked Finding or CAPA.
